### What I'm building

**REG121** — An agentic AI website builder for SMBs and agencies.

- Conversation → complete multi-page website in minutes
- Per-project AI component libraries for consistent design
- Multi-model pipeline: supervisor, design, build, and QA agents
- Self-hosted on bare metal Kubernetes

🌐 [reg121.com](https://reg121.com) · 🐦 [@reg121app](https://x.com/reg121app)
